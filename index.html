Shrink PNG images by converting to WebP

This PNG to WebP converter turns PNG files into WebP, a format built for smaller downloads and faster pages. PNG is lossless, which is why its files get big. WebP can store the same picture, including transparency, in far less space, and this tool lets you choose how much quality to trade for size. Expert tips and common mistakes

Don't use WebP for everything

Tiny, flat graphics with few colors are already small as PNG. WebP can come out larger. The size comparison on each result tells you when to keep the PNG.

Keep your originals

WebP here is lossy. Once you save at a low quality, detail is gone for good, so keep the source PNG if you may need it later.

Check text and fine lines

Screenshots with small text show artifacts sooner than photos. If letters look fuzzy, raise the quality to 90 or higher.

Remember where WebP won't open

Some older software and a few upload forms still reject WebP. If you need a file that opens everywhere, convert back with the WebP to PNG Converter or use a JPG.

Shrink dimensions too

A 4000-pixel-wide image will stay heavy at any quality. Resize first, then convert, or run the result through Compress Image File.

Troubleshooting

"Your browser can't save WebP files"

Your browser's encoder doesn't support WebP. Open this page in current Chrome, Edge or Firefox and try again.

"Not a valid PNG image"

The file may be corrupted or renamed from another format. Open it in a browser to check it displays, or export it again from its source.

The WebP is bigger than the PNG

That happens with small, flat graphics. Keep the PNG, or lower the quality and try again.

The image looks blurry or blocky

The quality is too low. Raise the slider to 85 or higher and convert again from the original PNG.

"Image is too large to convert"

Your browser ran out of memory for that many pixels. Resize the image first, or use a computer.

Download all only saved some files

Your browser may block several downloads at once. Allow multiple downloads for this site, or download one at a time.

Glossary

WebP
An image format from Google that supports lossy and lossless compression, transparency and animation.
PNG
Portable Network Graphics, a lossless format with transparency support.
Lossy compression
Compression that discards some detail to make the file smaller. This tool saves lossy WebP.
Lossless compression
Compression that keeps every pixel exactly. PNG is always lossless.
Alpha channel
The part of an image that stores transparency.
Compression artifacts
Blocky or fuzzy patches that appear when quality is set too low.

Frequently asked questions

Is this PNG to WebP converter really free?

Yes. There is no fee, no account, no watermark and no daily limit. Convert up to 30 PNG files per run as often as you like.

Are my PNG files uploaded anywhere?

No. Your images are converted inside your browser and are never uploaded. The page makes no network requests while you convert.

Does WebP keep the transparency from my PNG?

Yes. WebP supports an alpha channel, so transparent areas of your PNG stay transparent. Logos and icons keep their clean edges.

What quality setting should I use?

Start at 80. Photos usually look fine from 75 to 85. For sharp graphics, text or screenshots, try 90 or higher. Lower values give smaller files but more visible artifacts.

Will the WebP be smaller than my PNG?

Usually, especially for photos. Simple graphics that PNG already compresses well can occasionally come out larger. The tool shows both sizes so you can compare.

Does converting PNG to WebP lose quality?

This tool saves lossy WebP, so a little detail is traded for a smaller file. At 80 or above most images look the same to the eye.

Which browsers can create WebP files?

This depends on your browser's built-in encoder. Current Chrome, Edge and Firefox can save WebP. If yours can't, the tool shows a clear message instead of giving you a wrong file.

Do I need to sign up or install anything?

No. There is no login, no download and no extension. Add your PNG files, click Convert to WebP and save the results.

Does it work on my phone?

Yes, if your phone's browser can encode WebP. Tap the box to pick images, convert and download. Very large PNGs are safer on a computer because phones have less memory.

Does it work offline?

Once the page has loaded, conversion needs no internet connection because it runs in your browser. You do need to be online to open the page the first time.
